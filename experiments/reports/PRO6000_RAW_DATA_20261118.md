# PRO6000 raw performance data

Download the [performance tables and original timing records](https://github.com/TruNcat3/cuButterfly/releases/tag/pro6000-performance-20261118).
The data is bound to result/source commit `9731b35e01567efa4213a1beebab759bcb261b8a`;
the measured source remains a305d97 with its archived compatibility/workflow patches.

| File | Contents |
| --- | --- |
| full66_cases.csv | All 66 requests, own latency, semantics, mappings, errors and source identities; includes structured-2x2 seven and both zeta groups |
| full66_baselines.csv | All 264 comparator cells, including unsupported, inapplicable and failed cells |
| extensions_comparisons.csv | Separate FFT17 and explicit ALLOW_FP16_MMA9 comparisons |
| fixed_mapping_performance.csv / fixed_mapping_baselines.csv | Fixed-mapping samples and comparator results |
| timing_samples.csv | 1,729 original timing samples, seven per measured implementation, with cohort, request, implementation, median, protocol and sample units |
| pro6000-performance-20261118.zip | All tables, original published JSON/JSON.gz checkpoints, row envelopes, identity/calibration/selection receipts, error statistics and reports; approximately 2.75 MB |
| PERFORMANCE_MANIFEST.json / SHA256SUMS | Per-entry and downloadable-asset integrity checks |

The [asset index](../snapshots/pro6000_raw_data_20261118.json) records download sizes
and SHA-256. Verify downloaded assets with `sha256sum -c SHA256SUMS`.
The ZIP was checked for integrity and every bundled entry's hash before upload.

These are raw **performance records**, excluding large output-array payloads,
compiled binaries and installation data. Original paths/manifests inside JSON
remain provenance, not a claim that every historical referenced file is in this
small export. Complete output arrays remain on the measurement host.

The [Full66](PRO6000_FULL66_20261118.md),
[FFT17/MMA9](PRO6000_EXTENSIONS_20261117.md) and
[fixed-mapping](PRO6000_FIXED_MAPPING_SAMPLES_20261117.md) cohorts remain separate;
overlapping requests do not count as additional unique requests. Three Full66
GPU-NTT failures, floating accuracy review, provider gaps and model warning remain
unchanged. Failed or missing comparisons have no speedup ratio. This upload does
not imply all-green numerical acceptance or completion of CPU performance,
cyclic90, FFT-L, applications or mechanism/ablation tracks.
