# A100 研究测试收敛，2026-10-19

本轮将已有 A100 代表性测试转入结果核验与归档。保留全部负结果，只补齐
当前 CKKS 自动选择验收的缺项。当前代码和证据支持有限负载范围的性能结论，
尚不支持所有蝶形、所有配置全面领先或全局最优的声明。

项目作者与归属见 [项目说明](../docs/about.md)。原有
[A100 测试范围](scopes/a100_80gb_research_v1.json) 和历史结果保持原样。

## 本轮固定范围与完成条件

CKKS 自动选择验收沿用已经执行的 36 个配置。方法 I/N16384、方法 II/N16384、
方法 I/N65536，各包含 B=1/8/32，以及密钥切换、平方→重线性化→rescale、
该链再接密钥切换、槽旋转四个场景。方法和尺寸的组合来自当前应用范围，
不外推为完整参数链、生产安全参数或完整 bootstrap 覆盖。

目标设备是 A100 80GB PCIe，UUID 为
`GPU-2971e500-d3f6-d7e6-e5f2-cb67a06fff02`。每个配置测五条完整路径：
原生循环、cuButterfly 循环、原生核心阶段合批、cuButterfly 阶段合批、自动路径。
自动选择比较后两种 cuButterfly 组织的完整 Graph，以 7 轮×5 次回放的
中位数选择；独立测量轮换五路径，20 轮×10 次回放。调优与编译在计时外，
转换、打包还原及非 NTT 工作均在完整调用内。

收敛条件如下。

1. 36 个配置各有完整的普通计时、整数密文一致性和独立复测证据。
   `performance_eligible=false` 的争用、热降频与 profiler 记录全部排除，原件保留。
2. 选拔与复测样本的身份、数量、文件 hash、中位数、自动路径均值和 regret
   均通过现有汇总器核验。相同配置的五个比较行不算五个独立配置。
3. 报告各 cohort 的几何均值、范围和负点；不同构建、协议、设备的绝对时间
   不合并，旧数据不改称新版本测量。负点本身不触发无限重测。
4. 保存残差的诊断层次。当前 N16384/B1 长链的增量定位到 NTT 路径，
   局部算术、分段和线程所有权尚未完成单变量分离；这不是理论错误的证明，
   也不足以排除所有理论限制。

本轮已完成 36/36 个配置，包含 180 条配对行、504 条选择样本和 3600 条
独立复测样本。跨文件请求集合与固定矩阵完全一致，五组 metadata 均允许
普通性能报告，整数密文全部逐元素一致。每组按自身构建与协议单独统计，见
[完整对比表](../results/ckks_auto_schedule_20261019/comparison.md)。

最后补齐的是方法 I/N65536/B32 四场景。原进程被热保护拒绝；有效复测文件为
`results/ckks_auto_schedule_20261019/method1_n16_b32_cooled.csv`。它保持完整
batch 和重复预算，在选拔与独立测量每轮开始前于计时外降温。
metadata 用 `cool-before-selection-and-measurement-rounds-v2` 标记协议。
每个样本结束后继续检查热降频，失败仍拒绝整次运行，不删慢样本或放宽阈值。
新 cohort 对原生循环/原生阶段合批的几何平均加速比分别为 1.165×/1.134×。
旋转选循环，其余三个选阶段合批。旋转的独立复测 regret 为 2.8004%；
固定候选的复测排序仍支持循环，自动路径与同一循环图的单独计时差尚未
分离归因。本轮保留该残差，不为消除它扩大矩阵。逐点统计与旧失败记录见
[自动选择验收报告](../results/ckks_auto_schedule_20261019/README.md)。

## 三类论文实验的收敛边界

| 证据类型 | 可复用内容 | 尚未完成的部分 |
|---|---|---|
| 算子横评 | 已有 66 请求的公共语义横评，以及单列的 NTT 搜索修复与 xD 对照补充 | 匹配 GPU 对照缺口、浮点误差验收仍按原口径明示；不能把 CPU 列并入 GPU 加速比 |
| 机制与核心复用 | 当前组件控制、受限搜索、六行核心控制，以及本轮完整应用 trace | 固定两种核心×两种组织的同形状交叉表仍不完整；应用 loop/batch 选择复测不能代替这一消融 |
| 端到端 | FFT Poisson/固定滤波器 Graph，以及 CKKS 完整操作与短链 | QuaRot Graph 数值执行问题、完整 CKKS/TFHE bootstrap 适配与性能尚未完成；原有应用负点继续保留 |

这些范围来自 [已有证据缺口记录](research_evidence_gap_20261017.md) 和
当前论文证据台账。本次收敛
不取消后续工作，也不把单个 CKKS 子集的完成等同于整个库或论文完成。
硬件迁移独立推进，A100 结果不推算 H100、Ascend 或 V100 的表现。

工程上，当前 RNS 调优和应用 Graph 选择是请求级实测。RNS 已有公共 C++
接口，但尚未接入公共 C ABI、通用 planner 的全局 RNS 选择和安装级成本模型；
Graph 选择结果也尚未持久化。本轮验证的是这些已实现路径的执行效果，
不将其完成改称统一安装与所有前端已贯通。

## 收敛后的优化规则

保留 N16384/B1 小请求核心差距作为下一阶段有界优化目标。新增核心或映射
先在同语义、同核心边界的少量请求上确认，再通过公共候选接口接入，最后只
回归受影响的场景。现有合批、原位和自动选择功能直接复用。

近似持平项报告离散度与实际 regret，不为把每个点变成大于 1 而扩大样本范围。
trace 分开列 kernel 总时长、并集 busy 和首末 span；并发区间不能重复加到
完整调用延迟中。原始证据和可复现归因见
[性能复核](../docs/performance_followup_20261019.md)。
