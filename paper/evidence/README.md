## Frozen interface

Run from the repository root:

```text
python paper/tools/export_evidence.py
```

The command writes:

- `paper/generated/results_table.tex`: a standalone `table*` environment with
  twelve selected paired rows. The compact cohort IDs are decoded in the table
  note; the table uses only `\hline` and needs no table-package dependency.
  The table label is `tab:frozen-results`.
- `paper/generated/evidence_summary.json`: deterministic counts, claims, gaps,
  factorial-ablation status, and all source SHA256 values copied from the
  frozen manifest.

Use `--manifest` and `--output-dir` to export into a temporary location. The
compact `raw_selected_records.json` preserves the selected trial summaries and
all three A100 80GB trial values without copying the 819 KB acceptance
checkpoint.

The table reports measured transform microseconds. The Dao path includes
PyTorch interface and output-allocation costs as explained in the manuscript;
it is not an isolated arithmetic-kernel comparison. Every ratio is

```text
baseline_kernel_us / cubutterfly_kernel_us
```

Thus a value above one favors cuButterfly. Ratios are computed only within a
paired row. Cohorts are not pooled or averaged because their hardware, trial
count, protocol, and build provenance differ.

## Composition diagnostic

`method_cases.json` additionally freezes two same-workload FWHT candidates,
including standalone durations, demand estimates, scheduling floors, and
complete-plan timings. They reproduce the numerical example in the manuscript;
CPU replay instructions are in [COST_MODEL_CASE.md](../COST_MODEL_CASE.md).
These selected cases neither update the comprehensive result table nor add
new GPU measurements. The FFT core-control example uses the separate
`historical_motivation.json` archive and its original paired protocol.

The separate `a10080_composition_diagnostic` cohort freezes the 27-plan
physical-stage study. Its compact summary is in `manifest.json` rather than in
the performance table: all 81 public correctness trials passed; median model
errors are 4.998% (FFT), 4.109% (NTT), and 12.846% (FWHT), with a 40.287%
maximum FWHT error. One FWHT batch64/tile8 case measured 82.276 us unprofiled
against an independent serial-service sum of 80.200 us; its profiled concurrent
kernel time was zero. This supports an unresolved scheduling/concurrency
assumption, not a claim that every unprofiled schedule serializes. The
independent 3-group/32-tile scheduling-floor probe measured 343.562 us and is
kept as a distinct protocol.

## Cohort provenance

The `sources` array in `manifest.json` contains a relative path, role, and
SHA256 digest for every protocol or data file used to select a row. V100 source
builds are explicitly unknown. The A100 40GB environment has a recorded git
revision and binary digests, but that does not prove a source-build identity;
the manifest keeps it unknown. A100 80GB records the acceptance identity,
workload/profile/source-stage hashes, compile mode, and binary digests while
still avoiding a current-version claim.

`raw_selected_records.json` points each compact record back to its source file
and summary key. The five A100 80GB records include all paired and secondary
baseline trial values from their complete cells. Missing A10080 cells are not
represented as zeroes or synthetic results.
