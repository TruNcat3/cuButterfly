## 论述与相关工作

贡献从四项并列叙述收敛为统一执行构造、分层混合数据流两项。代码生成、校准、
有界搜索是落地机制，successor-aligned writeback 是交接规则，不把普通 tiling、
核心替换或搜索算法分别包装为首创。

Related Work 按变换生成/专用执行、张量编译/分块、层级数据流分组。八行四列表
对照 SPIRAL/FFTX、GPU 变换库、FlashFFTConv、Ansor/ROLLER、TensorIR、Welder、
Timeloop 与 cuButterfly 的优化对象和组织。比较已发表描述，而非假设其他系统
不能表示相同程序。来源及访问限制在 `literature/review_20261009/related_work_sources.md`。
本轮没有杜撰新文献条目，30 个实际引用均通过已有 BibTeX 生成。

方法保留 stage-bit 闭包、相邻集合交集、有限容量和生命周期论证，并简述可分离
多维变换的 axis/stage 标签推广。该说明不等价于所有维度、精度与变体已有高效 lowering。

## 图稿与实证边界

三张 7×2.2 英寸矢量图固定机制、规模/搜索和应用展示组织。
所有图内、CSV 和 manifest 均标记合成来源，随机 seed 固定。
这些值既不是实测也不是性能预测，不进入摘要、结果表或实证稿。
合成 renderer 不能通过移除水印自动变为证据 renderer。

RC2 箱型图、固定核心消融和历史性能记录仍保留各自 cohort。较早详细 scaling
图及协议图保留为附件资产，主文用紧凑说明替代重复图表。

发现并修正了“没有应用测量”的过时正文。历史 FNO 完整设备驻留 forward
约为基线 0.954×/0.952×，随机权重 SDPA QuaRot 延迟约 1.008×/1.003×。
后者不代表训练模型质量通过。原始短 QuaRot 记录的真实中位数为
2647.400203 ms，旧 README 使用了另一条样本；正文依据原始 JSON 复算。
证据快照及输入哈希在 `evidence/application_snapshot_20261009.json`。
旧记录不被覆盖，HEonGPU 单模数探针不冒充完整 RNS/bootstrap 应用测量。
